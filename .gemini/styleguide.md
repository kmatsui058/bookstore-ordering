# Gemini Code Assist スタイルガイド

このリポジトリには、実装とテストのガイドラインがあります。レビューでは、差分がそれに合っているかを確かめてください。

## 読むもの

- [実装ガイドライン](../docs/guideline.md): 層の責務、GoDoc とコメントの書き方、インターフェースの置き場所、集約とイベント、列挙型の網羅、生成物の扱い
- [テストガイドライン](../docs/test-guideline.md): TDD、テーブル駆動、Given-When-Then の名前、セッターを使わないテスト、モックの使い方

## レビューの仕方

- 指摘は、上のガイドラインのルールに基づいて行う。ルールの本体はガイドラインにあるので、ここに書き直さない
- `internal/presentation/api/gen/` や `mock_*/` の生成物が手で直されていたら、契約の定義かインターフェースを直して生成し直すよう指摘する
- ガイドラインにない観点で気になることは、ガイドラインに足すことを提案する
